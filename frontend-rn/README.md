# SHE SAFE AI — React Native Frontend

**Helping students take the first safe step toward human help.**

React Native + Expo + TypeScript frontend for the SHE SAFE AI student safety companion.

---

## Quick Start

### Prerequisites
- Node.js 18+
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator (Mac) or Android Emulator

### Install & Run

```bash
cd frontend-rn

# Install dependencies
npm install

# Start the development server
npx expo start

# Run on iOS simulator
npx expo start --ios

# Run on Android emulator
npx expo start --android
```

### Backend Connection

Update `src/services/api.ts` — change `BASE_URL` to match your backend:

| Environment | URL |
|-------------|-----|
| iOS Simulator | `http://localhost:8000` |
| Android Emulator | `http://10.0.2.2:8000` |
| Physical Device | `http://YOUR_COMPUTER_IP:8000` |

## API Endpoints Used

All endpoints are served by the existing FastAPI backend at `http://localhost:8000`.

| Endpoint | Method | Used In |
|----------|--------|---------|
| `/api/ai/analyze` | POST | AIChatScreen |
| `/api/ai/help-me-say-it` | POST | HelpMeSayItScreen |
| `/api/ai/safety-plan` | POST | SafetyPlanScreen |
| `/api/sos/start` | POST | SOSScreen |
| `/api/sos/stop` | POST | SOSScreen |
| `/api/journey/start` | POST | JourneyScreen |
| `/api/journey/check-in` | POST | JourneyScreen |
| `/api/contacts` | GET/POST/DELETE | ContactsScreen |
| `/api/map/points` | GET | SafetyMapScreen |
| `/api/routes/safe` | POST | SafeRouteScreen |
